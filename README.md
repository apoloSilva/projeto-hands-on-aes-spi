# AES Hands-on

Projeto Hands-on da trilha de RTL Design voltado ao desenvolvimento de um
acelerador AES com interface SPI, interface de dados com memória e aplicação
de técnicas de baixo consumo.

## Semana 1 Kick-off, Estudo e Ambiente

A primeira semana do projeto é dedicada a:

- estudar o algoritmo AES com base no padrão NIST FIPS 197;
- estudar o protocolo SPI;
- preparar a estrutura inicial do repositório;
- configurar o ambiente de compilação, lint e simulação;
- criar o backlog inicial do projeto.
